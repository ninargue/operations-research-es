# 🎲 Modelos Estocásticos

Los modelos estocásticos incorporan incertidumbre explícita mediante variables aleatorias y distribuciones de probabilidad. Son apropiados cuando los parámetros del sistema no pueden conocerse con certeza.

## Categorías

### Procesos de Markov
Procesos estocásticos donde el estado futuro depende únicamente del estado presente (propiedad de Markov).

| Subcategoría | Descripción |
|---|---|
| [Cadena de Markov](./Procesos_de_Markov/Cadena_de_Markov/) | Proceso en tiempo discreto con estados finitos |
| [Proceso de Feller](./Procesos_de_Markov/Proceso_de_Feller/) | Proceso de Markov en tiempo continuo con trayectorias regulares |

### Procesos Estocásticos
Familias de variables aleatorias indexadas por el tiempo.

| Subcategoría | Descripción |
|---|---|
| [Camino Aleatorio](./Procesos_Estocasticos/Camino_Aleatorio/) | Suma acumulada de pasos aleatorios independientes |
| [Martingala](./Procesos_Estocasticos/Martingala/) | Proceso cuya esperanza futura es igual al valor presente |
| [Proceso de Lévy](./Procesos_Estocasticos/Proceso_de_Levy/) | Proceso con incrementos independientes y estacionarios |
| [Proceso Gaussiano](./Procesos_Estocasticos/Proceso_Gaussiano/) | Proceso cuya distribución finita es multivariada normal |
| [Campos Aleatorios](./Procesos_Estocasticos/Campos_Aleatorios/) | Procesos indexados en espacios multidimensionales |
| [Proceso de Renovación](./Procesos_Estocasticos/Proceso_de_Renovacion/) | Modelado de fallas y reemplazos a lo largo del tiempo |
| [Proceso de Ramificación](./Procesos_Estocasticos/Proceso_de_Ramificacion/) | Modelos de crecimiento/extinción de poblaciones |

### Toma de Decisiones bajo Incertidumbre

| Subcategoría | Descripción |
|---|---|
| [Teoría de Decisiones y Juegos](./Teoria_Decisiones_Juegos/) | Decisiones racionales con múltiples agentes e incertidumbre |
| [Programación Estocástica](./Programacion_Estocastica/) | Optimización con parámetros aleatorios |
| [Árboles de Decisión](./Arboles_de_Decision/) | Representación gráfica de decisiones secuenciales |

## Aplicaciones por Sector

| Sector | Ejemplos |
|---|---|
| Banca y Finanzas | Valoración de opciones, gestión de riesgo, modelos de crédito |
| Seguros | Modelos de ruina, reservas técnicas, cálculo actuarial |
| Industria | Confiabilidad de equipos, mantenimiento predictivo |
| Salud | Propagación de enfermedades, ensayos clínicos |
| Telecomunicaciones | Modelos de tráfico, dimensionamiento de redes |
