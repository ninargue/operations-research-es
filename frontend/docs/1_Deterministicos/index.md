# 📐 Modelos Determinísticos

Los modelos determinísticos son aquellos en los que todos los parámetros del problema son conocidos con certeza. Dado un conjunto de entradas, el modelo produce siempre el mismo resultado.

## Categorías

### Lineal
Modelos cuya función objetivo y restricciones son lineales respecto a las variables de decisión.

| Subcategoría | Descripción |
|---|---|
| [Programación Lineal / Binaria](./Lineal/Programacion_Lineal/Binaria/) | Variables de decisión toman valores 0 o 1 |
| [Programación Lineal / Entera](./Lineal/Programacion_Lineal/Entera/) | Variables restringidas a valores enteros |
| [Programación Lineal / Continua](./Lineal/Programacion_Lineal/Continua/) | Variables continuas en un dominio real |
| [Programación Lineal / Mixta](./Lineal/Programacion_Lineal/Mixta/) | Combinación de variables enteras y continuas |
| [Modelo de Redes](./Lineal/Modelo_de_Redes/) | Flujo, transporte y asignación sobre grafos |

### No Lineal
Modelos donde la función objetivo o alguna restricción es no lineal.

| Subcategoría | Descripción |
|---|---|
| [Programación No Lineal](./No_Lineal/Programacion_No_Lineal/) | Optimización con funciones no lineales |
| [Métodos Clásicos](./No_Lineal/Metodos_Clasicos/) | Cálculo diferencial, KKT, gradiente |
| [Métodos de Búsqueda](./No_Lineal/Metodos_de_Busqueda/) | Búsqueda directa, Newton, quasi-Newton |

## Aplicaciones por Sector

| Sector | Ejemplos |
|---|---|
| Industria | Planificación de producción, mix de productos, corte de stock |
| Logística | Ruteo, asignación de carga, planificación de flota |
| Banca | Optimización de portafolios, asignación de capital |
| Transporte | Asignación de rutas, flujo en redes viales |
| Energía | Despacho económico, planificación de generación |
