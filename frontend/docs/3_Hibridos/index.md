# 🔀 Modelos Híbridos

Los modelos híbridos combinan elementos determinísticos y estocásticos, o integran múltiples técnicas de optimización y simulación para abordar problemas complejos del mundo real.

## Categorías

| Subcategoría | Descripción |
|---|---|
| [Teoría de Inventarios](./Teoria_de_Inventarios/) | Políticas óptimas de reabastecimiento bajo demanda determinística o aleatoria |
| [PERT / CPM](./PERT_CPM/) | Planificación y control de proyectos mediante redes de actividades |
| [Simulación](./Simulacion/) | Modelado computacional de sistemas complejos (Monte Carlo, eventos discretos) |
| [Programación Heurística](./Programacion_Heuristica/) | Algoritmos de búsqueda aproximada: genéticos, recocido simulado, tabú |
| [Programación Dinámica](./Programacion_Dinamica/) | Descomposición de problemas en subproblemas mediante principio de optimalidad |

## Aplicaciones por Sector

| Sector | Ejemplos |
|---|---|
| Logística y Retail | Gestión de inventarios, punto de reorden, lote económico |
| Construcción e Ingeniería | Planificación de obras, ruta crítica, gestión de recursos |
| Manufactura | Simulación de líneas de producción, detección de cuellos de botella |
| Banca | Optimización de carteras bajo restricciones complejas |
| Transporte | Ruteo con ventanas de tiempo, planificación de horarios |
| Salud | Programación quirúrgica, asignación de camas, gestión de stock de medicamentos |
